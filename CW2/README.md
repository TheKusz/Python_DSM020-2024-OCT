Finding and Analzying Growth Stocks to Support Investment Decisions (DSM020-2024-OCT)

There are no prerequisites for running the project, the Jupyter Notebook contains every necessary step. The database file includes the required data, which I extracted by running the web spider for an extended period, while in the current notebook the execution is configured to run only for a short, limited time.

Files:
- README.md: this file
- stockAnalysis.db: database containing all the data needed for the analyzation. No password is required.
- requirements.txt: dependencies (prettytable==0.7.2 is important, the %sql don't run on newer versions)
- commit_history.txt: an extraction of my commit messages
- CW2.ipynb: the project
